## About

Nook is an extremely lightweight Field of View (FOV)/Viewport adjustment tool, inspired by [SunnArt](https://www.curseforge.com/wow/addons/sunn-viewport-art) and [Sook](https://www.curseforge.com/wow/addons/sook-fov). It shrinks the size of the 3D game world inside the application window, which increases the FOV angle.

This effectively makes your widescreen monitor behave more like an ultrawide, at the cost of some vertical space. UI elements like chat, action bars, player frames, and damage meters can still be positioned over the empty space.

## Usage

`/nook` to bring up the Options GUI

Try not to go too crazy with the slider :)
